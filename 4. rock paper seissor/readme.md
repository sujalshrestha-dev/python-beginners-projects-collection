# ✂️ Rock Paper Scissors

A classic Rock, Paper, Scissors game with match modes — play Best of 1, 3, or 5 rounds against the computer.

---

## 🚀 How to Run

```bash
python rock_paper_scissors.py
```

---

## 🎮 How to Play

1. Choose a match type at the start
2. Type your choice each round (`rock`, `paper`, `scissors` or `r`, `p`, `s`)
3. First to reach the target wins takes the match!

---

## 🏆 Match Types

| Option | Mode | Description |
|--------|------|-------------|
| 1 | Best of 1 | First to 1 win |
| 2 | Best of 2 | First to 2 wins |
| 3 | Best of 3 | First to 3 wins |

---

## 🖥️ Example

```
Welcome to Rock, Paper, Scissors

Rock, Paper, Scissors (or r/p/s): r

Score: You 1 - 0 Computer

Rock, Paper, Scissors (or r/p/s): p
Computer chose: rock
You win this round!
Score: You 2 - 0 Computer
```
